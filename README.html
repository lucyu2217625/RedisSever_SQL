Redis 佇列管理介面

這是一份針對「Redis 佇列管理介面」的技術文件，旨在為開發者和維運人員提供深入的架構、功能和部署說明。

此專案是一個基於 Flask 的 Web 應用程式，提供了一個網頁介面，用於監控和管理 Redis 資料庫。專案透過 Docker Compose 進行容器化部署，並內建了一套自實作的 Redis 故障轉移機制，以確保服務的高可用性。

系統架構

本系統由多個容器化服務組成，透過 Docker Compose 統一管理與協調。

資料模型與核心功能

通用資料檢視器 (主頁)

  • List 型別資料:
    • 特殊行為: 為了保持介面整潔，應用程式在顯示 list 型別的資料時，會自動過濾掉內容為 {"task_id": "__INIT__"} 的初始化項目。
  • Hash 型別資料:
    • 特殊行為: 在主頁的通用檢視器中，為了快速概覽，只會嘗試解析每個 value 的 JSON 字串並提取 status 欄位來顯示。完整的 hash 內容建議透過「下載 JSON」功能查看，或在專屬頁面（如 equipments）進行編輯。

Worker Status 儀表板

  • 資料來源: 讀取以下三個 Redis Hash：prober_worker_status, LineNotify_worker_status, LotActions_worker_status。
  • 資料結構:
    • Field: Worker 的唯一名稱 (e.g., LotActions-RPA-BOT-01)。
    • Value: 一個 JSON 字串，其中必須包含 status 欄位。
    • 範例: HSET "LotActions_worker_status" "LotActions-RPA-BOT-01" '{"status": "busy", "floor": "2AF"}'

Script Update 功能

  • 注意事項:
    • API 回應: 每次 API 呼叫的成功或失敗狀態，都會以快閃訊息 (Flash Message) 的形式顯示在前端頁面上方，方便使用者追蹤結果。
    • ⚠️ 安全警告: 目前對外呼叫 API 時使用了 verify=False，這會停用 SSL 憑證驗證，使通訊過程面臨被中間人攻擊 (MITM) 的風險。在生產環境中，強烈建議將此設定移除，並確保目標伺服器擁有有效的 SSL 憑證。
  • conf.json 格式:
    [
  { "name": "RPA-Worker-Name-01", "url": "...", "X-API-KEY": "..." }
]
  • API 請求負載 (Payload) 格式:
    {
    "projectID": "86HklPenDDAsPmtc",
    "taskID": "KT59-m35TfGliLDH",
    "args": ["<source_path>", "<target_path>"]
}

Equipments & Contacts 資料頁面

  • 資料篩選: 這兩個頁面皆支援透過 floor, eqptype, 和 eqpid 參數進行 GET 請求的篩選查詢。
  • equipments 資料:
    • Redis Key: equipments (Hash)
    • Field: EQPID (設備 ID)
    • Value: 包含設備詳細資訊的 JSON 字串。
  • contacts 資料:
    • Redis Key: contacts (Hash)
    • ID 生成: 使用 contacts_id_counter key 透過 INCR 操作產生唯一序號。
    • Field: 序號 ID
    • Value: 包含聯絡人資訊的 JSON 字串。

部署與維運

環境需求

  • Docker
  • Docker Compose

初次部署

  1. 設定環境變數 (.env):

    FLASK_SECRET_KEY='your_strong_random_secret_key'
ALLOWED_QUEUES='processing_queue,failed_queue,task_queue,retry_queue,worker_status,dispatched_log'

  2. 啟動服務: docker-compose up -d --build

  3. 建立第一個管理員帳號: 初次部署時，需暫時修改 read_queue.py 中 register 路由的權限，註冊後再還原。

手動操作 Redis 資料

  • 進入 redis-cli:

    docker-compose exec redis-master redis-cli

  • 快速新增 equipments 測試資料:

    HSET "equipments" "T2K87" '{"EQPTYPE": "T2K", "TESTERIP": "1.1.1.1", "PROBERIP": "2.2.2.2", "LINEGROUP": "A", "floor": "2AF", "Action": "LotEnd"}'

  • 快速新增 contacts 測試資料:

    # 1. 取得新 ID
INCR contacts_id_counter
# 2. 使用上一步回傳的 ID 新增資料
HSET "contacts" "<new_id>" '{"EQPID": "T2K87", "EQPTYPE": "T2K", "Action": "Notify", "LINEGROUP": "2AF", "floor": "5F"}'
