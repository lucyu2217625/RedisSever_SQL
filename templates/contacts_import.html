支援格式

1. JSON：以任意序號為 key 的物件，每筆需包含 EQPID 欄位，例如：

{
  "1": {
    "EQPID": "T93A12",
    "EQPTYPE": "T93A",
    "Action": "test",
    "LINEGROUP": "NULL",
    "floor": "23F"
  }
}

2. Excel (.xlsx)：第一列為標題，欄位需包含：EQPID, EQPTYPE, Action, LINEGROUP, floor（大小寫不拘）

上傳後會先顯示「預覽」畫面，可勾選要套用的項目，確認後才會真正寫入資料庫。重複判斷依據為 EQPID + Action 組合（相同 EQPID 但 Action 不同會視為不同筆聯絡對應）。
